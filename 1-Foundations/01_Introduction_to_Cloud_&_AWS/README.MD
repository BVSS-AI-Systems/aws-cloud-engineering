# AWS Cloud Engineering Foundations

This repository contains foundational AWS Cloud Engineering learning materials designed to build a strong understanding of cloud computing concepts and AWS infrastructure.

## 📚 Contents

### Day 01: Introduction to Cloud & AWS
**File:** `Day01_Introduction.md`

Topics covered:

- What is Cloud Computing?
- Traditional IT vs Cloud Computing
- Benefits of Cloud Computing
  - Cost Efficiency
  - Scalability
  - Elasticity
  - High Availability
  - Global Reach
- Types of Cloud Computing
  - Public Cloud
  - Private Cloud
  - Hybrid Cloud
- Cloud Service Models
  - IaaS (Infrastructure as a Service)
  - PaaS (Platform as a Service)
  - SaaS (Software as a Service)
- Introduction to Amazon Web Services (AWS)
- AWS Core Services Overview
- Shared Responsibility Model

### Day 02: AWS Global Infrastructure
**File:** `Day02_AWS_Global_Infrastructure.md`

Topics covered:

- AWS Global Infrastructure Overview
- AWS Regions
- Availability Zones (AZs)
- Edge Locations
- Regional Architecture
- Fault Tolerance
- High Availability Design
- Data Residency and Compliance
- AWS Global Network Backbone
- Best Practices for Multi-AZ Deployments

## 🎯 Learning Objectives

After completing these modules, you should be able to:

- Understand cloud computing fundamentals.
- Differentiate between cloud deployment models.
- Explain cloud service models (IaaS, PaaS, SaaS).
- Describe AWS core concepts and services.
- Understand AWS Global Infrastructure components.
- Differentiate Regions, Availability Zones, and Edge Locations.
- Design applications for high availability and fault tolerance.

## ✅ Key Takeaways

- Cloud computing provides on-demand access to computing resources.
- AWS is the world's leading cloud platform with a global presence.
- Regions contain multiple Availability Zones for redundancy.
- High Availability and Fault Tolerance are critical cloud design principles.
- Understanding AWS infrastructure is the foundation for all AWS services.
