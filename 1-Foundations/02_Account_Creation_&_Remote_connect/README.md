# Account Creation & Support Plans

This folder covers the fundamentals of creating and securing an AWS account along with understanding AWS Support Plans. It introduces account setup, billing configuration, free tier usage, security best practices, and the different support options available for individuals, startups, and enterprises.

## Topics Covered

- AWS Account Creation Process
- Billing and Payment Setup
- AWS Free Tier Overview
- Root User Security
- Multi-Factor Authentication (MFA)
- AWS Billing Dashboard
- Cost Management Basics
- AWS Support Plans
  - Basic Support
  - Developer Support
  - Business Support
  - Enterprise Support

## Learning Outcomes

After completing this module, you will be able to:

- Create and configure an AWS account securely.
- Understand AWS billing and free tier limitations.
- Apply security best practices for root accounts.
- Monitor and control cloud spending.
- Differentiate between AWS support plans.
- Choose the appropriate support plan based on workload requirements.

## Prerequisites

- Email Address
- Phone Number
- Payment Card for AWS Account Verification
- Basic Understanding of Cloud Computing

## Why This Module Matters

A properly configured AWS account is the foundation of every cloud environment. Understanding account security, billing mechanisms, and support plans early helps prevent security risks, unexpected costs, and operational challenges as you progress in your cloud journey.
