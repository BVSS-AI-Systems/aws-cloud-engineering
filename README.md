## A workspace for discovery

Every topic starts with a question: **how does this work, and what can I build with it?**

This repository is where I explore AWS and cloud engineering through notes, experiments, and practical tasks. For each topic, I’ll work through multiple exercises, explain the concepts in my own words, and collect resources that help me go further.

I’ll share updates step by step as I build—including the decisions, mistakes, fixes, and small discoveries along the way. Wherever they make an idea clearer, I’ll add architecture diagrams to show how the pieces connect.

## What’s inside

| | What I’ll share |
| :--- | :--- |
| **📝 Notes** | Clear explanations, important concepts, and details worth remembering. |
| **🛠️ Hands-on tasks** | Multiple exercises for each topic, with implementation steps and results. |
| **🏗️ Architecture** | Diagrams and design notes that bring connections and workflows into view. |
| **🔎 Discoveries** | Problems I encounter, how I troubleshoot them, and what I learn. |
| **🔗 Resources** | Helpful documentation, articles, videos, and references for deeper exploration. |

## The topics ahead

**Cloud foundations → AWS services → Infrastructure → Secure delivery**

| Focus | What I’ll explore |

| **Foundations** | Cloud concepts, Linux, AWS setup, IAM, and cost management |
| **AWS services** | Compute, storage, networking, databases, DNS, and serverless |

| **Infrastructure & automation** | CloudFormation, Terraform, and scripting |
